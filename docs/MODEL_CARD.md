# Event model card
kNN with k=3 and Euclidean distance over normalized acceleration, speed and sample age. Nine hand-authored synthetic training observations across habitual movement, braking to review and stale GPS. Runs locally; no model API. Output is an event category and advisory queue priority, never an individual driver score. Neighbor agreement is displayed as synthetic confidence, explicitly uncalibrated. No independent test set or real-world accuracy claim. Distances outside training support can be misleading; human context remains necessary. No driver identity, training reuse or external transmission.
